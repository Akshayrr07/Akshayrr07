## Projects

### [Satellite Road Extraction](https://github.com/Akshayrr07/Road_extraction) · [Live demo](https://road-extraction-livid.vercel.app/)
Semantic segmentation of satellite imagery to extract road networks. U-Net with a ResNet34 encoder in PyTorch, served through a Flask API with a React frontend, and TIFF input support. Frontend on Vercel, backend on Render. Built for Smart India Hackathon, where our team was a finalist.

`PyTorch` `U-Net` `Flask` `React` `Vercel` `Render`

### [Pneumonia Detection from Chest X-rays](https://github.com/Akshayrr07/pneumonia-detection)
An end-to-end pipeline rather than a single notebook: dataset construction from several sources, duplicate removal and label normalisation, leakage-safe train, validation and test splits, multiple CNN approaches, and hierarchical classification. The model is hosted on Hugging Face and the app runs on a cloud frontend and backend. For research use, not clinical diagnosis.

`PyTorch` `CNN` `Computer Vision` `Hugging Face` `Flask`

### [Legal Document AI](https://github.com/Akshayrr07/Legal_document_AI)
An OCR and NLP pipeline for analysing legal documents, with a backend API and a web frontend, packaged with Docker.

`Python` `OCR` `NLP` `Docker`
